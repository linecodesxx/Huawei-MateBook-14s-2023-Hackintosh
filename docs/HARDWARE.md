## Подтверждённые ACPI-узлы

- GPU: `\_SB.PC00.GFX0`.
- EC: `\_SB.PC00.LPCB.HWEC`.
- Клавиатура: `\_SB.PC00.LPCB.PS2K`.
- Тачпад: `\_SB.PC00.TPD0`; подключение к I2C0.
- Ветка S9801: адрес 0x15, HID descriptor register 0x20, firmware bus speed 400 kHz.
- Поле STAS управляет доступностью AWAC и legacy RTC.
- В корне DSDT есть 16-битное поле PNLF. Его нельзя вслепую переименовывать как устройство подсветки.
- Заводской DSDT объявляет 64 CPU-устройства. Это не означает наличие 64 физических процессоров и само по себе не доказывает ошибку.

## Что ещё измерить

- Enabled APIC IDs и их соответствие CPU-объектам.
- UEFI memory map и обоснование MMIO-исключений.
- GPU GGC/GMS, L3/topology, частоты.
- eDP lane count/link rate, PWM и способ управления подсветкой.
- Собственную карту USB и полную конфигурацию аудиопинов.

Ни один серийный номер или другой уникальный идентификатор для этих измерений публиковать не требуется.
