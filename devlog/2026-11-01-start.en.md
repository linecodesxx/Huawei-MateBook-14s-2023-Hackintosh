# 2026-11-01 — Starting the public journal

[Русский](2026-11-01-start.md) | **English**

**Summary:** The kernel reaches ACPI table loading on a Huawei MateBook 14s 2023. No installer or accelerated desktop has been demonstrated. We compared the saved EFI and OEM tables with D16/X1 and selected a staged D16-based port.

I am starting to document the attempt to run macOS on a Huawei MateBook 14s 2023 with an i7-13700H and Iris Xe A7A0.

## Where we stopped

The latest photo shows a kernel that has already started. Early service messages and ACPI warnings are followed by a message reporting successful table loading, then a PCI banner, with no further text.

An earlier configuration stopped around EXITBS. That is not the state of the latest attempt; these two states must not be conflated.

## What the files revealed

We examined local hardware data, OEM ACPI and archives of the current EFI, X1 and D16. The archived installer EFI largely follows X1 stage1. The D16 has the same early Booter/Kernel settings, with additional Huawei-specific solutions.

Matches were confirmed for Fn keys, EC/keyboard paths and the SN6140 audio codec. The touchpad differs: ours is S9801 rather than BLTP7840. The D16 graphics profile for 48 EU is also unsuitable for a processor with 96 EU.

The D16 patch applies to the selected X1 source snapshot without conflicts. This is a useful reproducibility check, but not a hardware success.

## Chosen direction

An EFI built for this laptop, based on a consistent X1/NootedGreen stack with the D16 Huawei layer ported over. First, try to reach the installer without acceleration; then address Metal and peripherals.

## Next checkpoint

Compare the latest local changes, establish the current configuration and choose one test that distinguishes between hypotheses about the current stall. Do not repeat all previous experiments without analyzing their results.

## What cannot yet be claimed

There is no working EFI or Metal confirmation on this 14s yet. The cause of the stall has not been found. Neither PCI nor Iris Xe has been identified as the culprit from a single last log line.

Raw reports and photos are not published. Only technical conclusions and sanitized excerpts go into the journal.
