# Huawei MateBook 14s 2023 — Hackintosh

**Русский** | [English](README.en.md)

**i7-13700H · Iris Xe A7A0 · OpenCore · обновлено 5 ноября 2026**

На Huawei MateBook 14s 2023 (HKFG-XX) подтверждена **macOS Sequoia Recovery 15.8 [24H23] до Дисковой утилиты**. Пользователь подтвердил работу встроенных клавиатуры и тачпада. Рабочая EFI сохранена локально; готового EFI-релиза здесь пока нет.

| Возможность | Статус |
|---|---|
| Recovery и Дисковая утилита | Работают |
| Встроенные клавиатура и тачпад | Работают; тачпад в режиме опроса |
| Все 20 логических CPU | Включены в конфигурации USB; новый запуск ещё не подтверждён |
| GPU/Metal, сеть, установленная macOS | Не проверены |

Наблюдатель локализовал ожидающий `TypeCBPC::probe`: прошивка предоставляла `HWEC`, а драйвер ждал буквальное имя `EC`. Именованный Darwin-only EC устранил эту преграду; временный обход ожидания UUID отключён. Затем добавлены PS/2-клавиатура и I2C-тачпад. После успеха удалён только `cpus=1` для следующего теста 20 потоков. Однопроцессорная рабочая база сохранена, USB проверен и размонтирован; автоматической перезагрузки не было.
